# claude-butler-template

Claude Code を「専属バトラー」にするための雛形です。
セッション、PC、モデルが変わっても、それまでの経緯を覚えたまま続きから相談できるようにします。

## できること
- **経緯を引き継ぐ**：Claude がセッションを始めるときに記録を読み、終わるときに書き足します。あなたが記録を頼む必要はありません。
- **別の PC やクラウドでも続けられる**：記録はこのフォルダ内のファイルなので、Git で同期すればどこでも同じ記録を使えます。
- **Git に上げたくない情報を分けられる**：`private/` は Git の管理外です。
- **重い作業は専門エージェントに任せる**：バトラーは中継に専念します。専門のルールとバトラーのルールは混ざらないようにします。

## 使い方
1. このページ右上の「Use this template」→「Create a new repository」を選びます。Owner は自分のアカウント、名前は自由（例：`butler`）、公開範囲は **Private** にして「Create repository」を押します。
   - fork ではなく「Use this template」を使ってください。公開リポジトリの fork は非公開にできないため、記録が公開されてしまいます。
2. 手元に clone して、そのフォルダで Claude Code を開きます。
3. 「はじめまして。バトラーとしてよろしく」など、普段どおりに話しかけます。

最初は `profile.md` がほぼ空です。会話をしながら、Claude が書き足していきます。

## ファイル構成
| ファイル | 内容 |
|---|---|
| `CLAUDE.md` | バトラーの役割と、記録・同期・委任のルール（Claude Code が毎回自動で読み込む） |
| `profile.md` | あなたについて分かったこと（環境・好み・関心） |
| `open-items.md` | 続いている話題・宿題 |
| `journal/` | 日ごとのやりとりの要点 |
| `knowledge/` | 調べて答えた内容（テーマ別・確認日付き） |
| `projects.md` | 専門エージェントや別プロジェクトに任せている案件の一覧 |
| `templates/specialist-agent.md` | 専門エージェントの雛形 |
| `private/`（自分で作る） | Git に上げない情報の置き場 |

## 注意
- 記録には会話の内容が残ります。リポジトリは必ず**非公開**にしてください。
- パスワードや API キーなどの秘密情報は、記録に書かないでください。
